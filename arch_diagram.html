Encoder Attention/Graph Refinement Wavelet Upsampler Output Skip path
INPUT
12-band Sentinel-2 · 64×64 B1–B12 · resampled to 10m grid
Shape [B, 12, 64, 64]. Bands grouped by native GSD: 10m (B2,B3,B4,B8), 20m (B5,B6,B7,B8A,B11,B12), 60m (B1,B9). All co-registered to the 10m grid.
TRI-STREAM PARALLEL ENCODING
10m GroupEncoder 4ch→128ch · 2×Conv3×3
Bands B2,B3,B4,B8 (4 channels). Conv2d(4→128,k=3)+GELU+Conv2d(128→128,k=3). Output [B,128,H,W].
20m GroupEncoder 6ch→128ch · 2×Conv3×3
Bands B5,B6,B7,B8A,B11,B12 (6 channels). Conv2d(6→128,k=3)+GELU+Conv2d(128→128,k=3). Output [B,128,H,W].
60m GroupEncoder 2ch→128ch · 2×Conv3×3
Bands B1,B9 (2 channels). Conv2d(2→128,k=3)+GELU+Conv2d(128→128,k=3). Output [B,128,H,W].
SpectralGraphMixer 3-node graph · 4 attn heads
Treats 3 feature maps as graph nodes [B,3,128,H,W]. Learned adjacency (softmax edge logits). Q·K attention across nodes → weighted V aggregation → GroupNorm. Output [B,128,H,W].
CrossResGatedFusion Bilinear align + σ-weighted
Bilinear-aligns 20m+60m to 10m size. Concat all 3 → Conv1×1→GELU→Conv1×1 → softmax(2 gates) → weighted sum + Conv3×3 refine. Output [B,128,H,W].
SpectralMamba Per-pixel 12-band mixer
Each pixel's 12 bands treated as a 1D sequence. Value-embed + (wavelength_nm, GSD_m) positional embed → Conv1d(k=3) mixer → Sigmoid gate → mean-pool → Conv1×1 to 128ch. Output [B,128,H,W].
Σ Sum → pre_refine NAFStack (4 blocks) graph+gated+spectral → [B,128,H,W] · LayerNorm+CA+SA
Element-wise sum of 3 streams. Then 4× NAFBlocks: LayerNorm2d → DW-Conv3×3 → Channel Attention (SimpleGate) → Conv1×1 → dropout + residual. Stabilizes fused features.
HAAR WAVELET DECOMPOSITION
HaarDWT2D → LL [128,32,32] + LH/HL/HH [384,32,32]
1-level 2D Haar DWT. Splits [B,128,H,W] → Low subband [B,128,H/2,W/2] + High subband [B,384,H/2,W/2] (LH+HL+HH packed channel-wise).
SpatialMamba (LL) ×2 Horiz(1×7)+Vert(7×1) depthwise
2× SpatialMambaBlock on LOW freq: LayerNorm → project to u+gate → DW-Conv(1×7) + DW-Conv(7×1) → mix → tanh → sigmoid-gate → learnable scale residual. Captures long-range spatial dependencies.
StripConvStack (HH) ×2 384ch → edge/texture refine
2× StripConvBlock on HIGH freq subbands (384ch). Strip depthwise convolutions + channel gating + residual. Preserves and enhances edge/texture information for SR.
iHaarDWT → post_refine NAFStack (4 blocks) Reconstruct → [B,128,H,W] → further NAF refinement
Inverse Haar DWT fuses low+high subbands back to [B,128,H,W]. Then post_refine NAFStack (4 blocks) cleans reconstructed features before upsampling.
PROGRESSIVE 4× UPSAMPLER
2× Stage 1 Conv(128→512) → PixelShuffle(2) → NAFBlock
Conv2d(128→512,k=3) expands channels, then PixelShuffle(2) rearranges to spatial [B,128,128,128]. 1× NAFBlock refines. Doubles spatial resolution.
→
2× Stage 2 Conv(128→512) → PixelShuffle(2) → NAFBlock
Same as Stage 1. Another PixelShuffle 2× to reach [B,128,256,256]. Final NAFBlock at HR scale. Total: 4× upsampling (64→256).
UQ OUTPUT HEADS
μ Head (mean) Conv1×1 → 12 bands · 256×256
Conv2d(128→12,1×1). Predicts SR reflectance mean. Shape [B,12,256,256].
σ² Head (logvar) Conv1×1 → 12 bands · 256×256
Conv2d(128→12,1×1). Predicts per-pixel aleatoric uncertainty (log variance). Shape [B,12,256,256]. exp() gives variance.
RESIDUAL SKIP + FINAL OUTPUT
Skip Conv 1×1 12→12 bilinear-upsampled
self.skip = Conv2d(12,12,1) applied to raw LR input → bilinear interpolate to 256×256. Preserves spectral baseline / prevents catastrophic forgetting.
⊕
SR Output (mean + skip) [B, 12, 256, 256] · 2.5m Equivalent
mean = μ_head(high_res) + bilinear(skip(x)). Final 12-band SR output. Logvar returned separately for uncertainty maps and NLL loss.
